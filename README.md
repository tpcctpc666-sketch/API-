# API 中转站对比（优缺点 / 价格一览）

- **链接**：已去掉 `aff` / `ref` / `invite` / 邀请 `code` 等推广参数，保留可点击官网地址。
- **价格口径**：如无特别说明，单位为 **人民币 / 百万 Token（进/出）**；价格随时变动，以各站实时为准。
- **阅读方式**：每站按 **官网 → 价格 → 优点 → 缺点** 排列，便于快速对比。

### 赛艺（Selart）API
| 项目 | 内容 |
|------|------|
| **官网** | [https://open.selart.cc/](https://open.selart.cc/) |
| **价格 / 计费** | 全站比例 **1:1（1 美元 = 1 人民币）**；页面余额显示为 USD，但按 1:1 折算。支持**按量**和**按次**计费，且按次模型池较丰富。按量侧示例：`claude-opus-4-6` 约 **¥3/15**、`claude-sonnet-4-6` 约 **¥2.76/13.8**；GPT 侧如 `gpt-5.4` 约 **¥2.25/13.5**。按次侧有多档 Gemini/Claude 低单价分组（例如约 **¥0.03~0.18/次** 的 Gemini、约 **¥0.18~0.38/次** 的 Claude 部分分组）。最低充值门槛 **10**（以站内为准）；大额充值有阶梯折扣。社群反馈每周四“疯狂星期四”活动，充值/订阅可到 **8 折**，部分分组可叠加形成“折上折”（以当期公告为准）。 |
| **优点** | **Claude 价格带有优势**：`Opus 4.6` 与 `Sonnet 4.6` 按量价格在对比站点中属于有竞争力区间；**按次场景友好**：多档低单价按次模型，对酒馆、批量任务、上游转发更实用；**活动叠加空间大**：周四 8 折叠加部分分组倍率，活动期价格更有吸引力；**模型覆盖全**：OpenAI/GPT、Claude、Gemini、DeepSeek、GLM、Kimi 等都有；**分组灵活**：可按价格/稳定性选特价、逆向、官转、专属分组；**社区反馈较好**：有微信群和管理员支持，沟通响应快。 |
| **缺点** | **并非全模型最低价**：例如 `GPT-5.4` 主档相较部分低价站点偏高；部分 `Codex` 档位也不是全网最低；分组较多，新用户初次上手需要花时间理解差异；风控机制较严，异常行为可能触发限制。 |
| **推荐** | 追求 **Claude 4.6 系列性价比** 的用户；需要按次低单价进行酒馆调用、自动化流水线、上游接入分发的用户；对价格敏感可优先关注限时特价+周四活动，对稳定性敏感可选官转/优质分组。 |
